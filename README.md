# PurgeRun

Top-down shooter rogue-like made in Godot 4.6. Survive 5 waves against escalating enemy types and a boss. Choose upgrades between waves.

- **Desktop:** download latest release from [Releases](#) _(after Phase 10)_

## Controls

| Action | Keys |
|---|---|
| Move | `W A S D` / Arrow keys |
| Aim | Mouse |
| Shoot | Left click |
| Dash | `Space` / `Shift` |
| Pause | `Esc` |

## Build from source

Requires Godot 4.6.2+ (Standard / GDScript build).

```bash
git clone <this repo>
cd GodotRogue
"C:\Apps\Godot\Godot.exe" --path . --editor   # open editor
"C:\Apps\Godot\Godot.exe" --path .             # run game
```
